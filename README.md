# Michael Mdzoole - Personal Portfolio

This is my personal portfolio website created for the Multimedia Tools and Application assignment. It showcases my background, technical skills, and programming projects.

## Technologies Used
- **HTML5:** Semantic structure, tables, lists, formatting.
- **CSS3:** Flexbox, Grid, animations, transitions, responsive design.
- **JavaScript:** DOM manipulation, scroll events, IntersectionObserver, typewriter effect.

## Features
- Responsive navigation and layout.
- Animated hero section with typewriter effect.
- Interactive hover states and scroll reveal animations.
- Educational background presented in an HTML table.
